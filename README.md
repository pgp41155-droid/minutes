# Minutes Expansion Atlas

Static research dashboard for evaluating Flipkart Minutes expansion markets and comparing ward-level store-search areas. Independent research project; not an official Flipkart product.

## View and publish

Open `index.html` locally, or publish the repository through GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

No build, server, credentials or API keys are required. All application assets are included. Navigation uses URL fragments and assets use relative paths, so project-repository hosting is supported.

## Research scope

The dashboard is a fixed research snapshot, not a live operational feed. Commercial data is dated 8 October 2026 and map work 9 October 2026. Method & evidence in the application contains source links, dates and model assumptions.

Unconfirmed Flipkart presence does not establish absence. Market sizes and entrant ambitions are modelled scenarios. Ward pins identify search areas, not verified leasable premises. Satellite imagery dates differ from the research date. Straight-line network comparisons do not demonstrate ten-minute road delivery or current traffic conditions. Competitor store coordinates and market shares are not represented as verified when unavailable.

Retain the in-app evidence, imagery attribution and model labels when sharing or modifying this project.
